# 图书与推荐

## 业务模型

图书独立保存真实书目，账号、主题标签和主站会话与社区共享。`Book` 保存版本书目和出版来源，`BookState` 保存每位读者当前的想读、在读、读过和收藏，`BookLoan` 保存借出、应还、归还时间，`BookReadingRecord` 保存有时间和来源的历史事件。

主站 `/books` 默认按当前会话账户展示三路融合推荐，显式全库模式按书名排序。支持全库、推荐、主题、大学学习用书、个人书架和分页，`?book=id` 打开保留下层筛选的详情弹层，`/books/:id` 是可访问的书籍链接。`/books/history` 只展示当前会话账户的历史。写接口由服务端会话确定账户，不接收客户端传入的操作者 ID。借阅最多同时 5 本，每次 30 天，图书初始 3 册。借阅中的用户图书对由唯一 activeKey 防止重复，归还清空 activeKey。重复借阅返回原借阅，重复归还不重复记录历史。同事务写入借还 outbox 事件，通知失败不回滚业务。

来源按操作者的服务端 User.source 继承，Synthetic 账号的操作不会被标为真人。库存是本应用中的演示流通数量，不代表学校图书馆馆藏。内部来源、采集时间和书目 URL 留在数据库和工具归档，不进入公开图书 DTO。

## 三路算法

`packages/recommendation/books.ts` 是无数据库与网络依赖的纯 TypeScript 模块。`resultCount` 是输出 N，`neighborCount` 是相似读者或相似图书数量，两者独立。

- 用户协同过滤：建立 Map 用户到 Map 图书权重的稀疏矩阵。借阅 3、归还 1，阅读状态只采用同一用户同一书的最新状态，在读 2、读过 4。180 天半衰期，过滤无效和未来时间。使用余弦相似度选择邻居，对未读候选聚合邻居归一化阅读权重的贡献。
- 物品协同过滤：从归一化用户矩阵建立图书到读者的倒排索引，计算图书之间的余弦相似度。相似度再乘共同读者数 /（共同读者数 + 2），避免一次共同阅读成为强证据。聚合目标读者已有条目贡献，保留具体来源图书、相似度和共同条目数。
- 内容推荐：按书籍主题生成 TF-IDF 向量，与显式兴趣、真实借还历史和当前阅读/收藏状态形成的内容兴趣向量计算余弦相似度。想读和收藏不进入借阅协同矩阵。状态反复切换不累计刷画像，取消信号后只保留仍然成立的历史事实。
- 三路融合：分别对本次候选中各路得分除以该路最大值，默认权重 0.35 / 0.35 / 0.30，只在存在正证据的通道间重新归一化。各路均无证据时按稳定 ID 排序，零向量相似度为 0。已借阅或仍在读/读过的书从候选中排除。最终通过既有真实最小堆选择 Top-N，并返回 retain / replace / skip 过程。

共享兴趣是可关闭的弱扩展：帖子当前点赞/收藏和有效 VIEW 时长投影到共享标签，不把历史点赞事件与当前状态重复累加。VIEW 使用 30 天半衰期，按每用户每帖限幅，再按每主题限幅 1.5，图书画像只接收其 0.25 倍。取消点赞/收藏会移除对应当前状态信号，独立的真实阅读信号仍按时效保留。投影不回写原始行为，避免双向反馈无限放大。书到社区的投影由主站快照层统一接入。

Studio `/books` 使用独立 `readonly/fileMustExist` 驱动读取同一数据库，支持三路独立运行和融合，显示稀疏矩阵原始值/归一化值、相似读者、内容画像、逐书来源贡献、真实堆选择步骤和跨域开关对比。只读路径不导入写数据库单例，也不回退到离线 seed。

## 角色自主选书

日常巡游从完整书库按同一融合引擎选取 8 本候选，同时加入当前借阅和最近想读、在读的图书。上下文提供真实简介摘录、作者、主题、阅读状态、收藏、库存和本人借阅，逐书列出可用借还与阅读动作。调度只给可用动作弱偏好，由角色决定是否选书。借阅不等于读完，只有已在读且有完成依据时才考虑读过，通知和私聊任务仍遵守各自动作范围。

## 采集和恢复

仅采集公开书目元数据和封面，不获取电子书正文，不生成或补写书籍事实。原始数据与封面验证记录保存在 `CAMPUS_DATA_DIR/books`（默认 `.data/books`），可追溯来源与时间。Google Books 无 key 探针返回 429（项目日配额为 0），未继续请求。豆瓣公开书目列表取得 665 候选，逐详情 99 本后遇到 403 即停止，不更换 IP 或绕开限制。列表中的作者、出版社和简介摘录直接来自对应书目页，不把列表摘录冒充完整简介。缺失 ISBN 留空，已有 ISBN 校验 ISBN-13 校验位。

豆瓣封面 CDN 要求其对应书目页 Referer，使用正常书目页图片加载参数后得到真实 JPEG，未继续请求被限制的书目详情。图灵来源使用出版社公开目录 API 和官方 LargeCover，保留响应原文，专业数学、计算机课程书和科普内容用于补充完整元数据。图片逐张进行尺寸检查、实际解码和哈希记录，合格图片转换为本地 WebP，页面从本应用的只读图片接口加载，避免依赖第三方防盗链与答辩现场网络。无法读取或解码的封面不入库，不用生成图补真实书的封面。

按 ISBN 和规范化书名/作者去重，移除版次与装帧差异，优先完整出版社元数据。同名不同作者保留，系列的不同作品和上下册保留。规范化无法证明所有跨语种译名都指向不同作品，不能把该过程称为人工逐书作品鉴定。大学分类排除中小学、儿童和常见语言培训练习材料，并控制选入数量。最终数量和覆盖以 `import-report.json` 为准。

从 Project 根目录执行：

```sh
# Python 采集依赖可放在项目之外的临时虚拟环境
python tools/books/collect.py
python tools/books/collect-turing.py
node tools/books/verify-covers.ts
node tools/books/verify-covers.ts --turing
python tools/books/enrich-source-tags.py
python tools/books/repair-list-metadata.py
node tools/books/import.ts --sample
node tools/books/import.ts
# 仅明确需要 Synthetic 账户的合成演示历史时使用
pnpm data:books --seed-demo
node tools/books/bundle.ts pack
node tools/books/bundle.ts unpack
node tools/books/import.ts --from-bundle
```

采集器串行限流并读取已有检查点，403/429 停止该来源，不自动改代理绕过限制。封面校验串行限流，403/418/429 停止，不把错误页当封面。不得并行运行多个封面校验器。重新导入仅 upsert 合格书目，保留无关书籍和读者记录，不重置产品数据库。

`tools/books/catalogue.tar.gz` 保留真实书目、原始响应、封面、校验清单和导入回执，不包括费用与凭据。pack 使用独立锁、前后摘要核对和原子 rename，采集完成后再运行。unpack 在临时目录核对归档摘要，现有本地文件有差异时停止，禁止覆盖本地成果。恢复后先导入元数据，图片接口只公开已存在 Book 的封面。`pnpm data:books` 默认按 accepted.json 恢复已验收的完整书库，需要重新筛选采集候选时显式执行 `node tools/books/import.ts`。

`--seed-demo` 只作用于 source=Synthetic 的已有账户，不动真人账户。每个账户按显式兴趣选择少量读过图书，并保存明确 Synthetic 来源的演示阅读记录和已归还借阅历史，不伪装成学校流通数据，不占用当前库存。重复运行按确定性 ID 跳过已有演示批次。该数据用于算法演示与内部验证，不能报告为真实学生推荐准确率。

## 验证边界

静态检查、生产构建、算法临时对照和实际领域/API操作分别记录。最小闭环已核对重复状态请求不重复记录、重复借阅复用同一借阅、重复归还不重复记录、库存借出/归还一致、Synthetic 来源继承，未借阅账户不获得他人借阅详情。算法核对零向量、未来记录排除、N=0、N 大于候选、取消想读/收藏、跨域开关以及稳定并列排序。生产构建通过不代表所有移动端交互与并发库存竞争都已经浏览器验收。

## 当前书库回执

本轮有限采集最终入库 **700 本**，其中豆瓣公开书目 520 本，图灵官方出版目录 180 本，全部带可解码并持久保存的真实封面。277 本带通过校验的 ISBN-13，278 本有完整详情简介，其他书籍展示对应来源的真实列表简介摘录。267 本标记为大学学习用书（38.1%），该分类包含专业基础和技术学习书，不把所有书声称为正式指定教材。688 个书名含中文，另有《13 67》等中文版本书名与少量原版外文专业书，语种是依据已采集出版信息的分类，不能替代版权页的语言鉴定。

学科覆盖文学、历史、社会学、心理学、科普、艺术、计算机和大学学习。课程学习内容包括微积分、线性代数、概率统计、数学分析、数据结构与算法、计算机组成、操作系统和网络。保留来源原始主题，并把明确主题映射到共享兴趣，过滤出版社营销标签和作者姓名标签。书目源有缺价格字段的列表，出版社解析已改为识别明确出版机构或出版日期前字段，避免将译者误认作出版社，无法确认出版社的候选未入库。

200 个 Synthetic 账户共 3200 条明确合成的演示历史（2000 条读过、600 次借出和600 次归还），600 条借阅均已归还，不占当前库存。最小闭环另留下 6 条 Synthetic 操作记录和 1 条已归还借阅。Real 账户图书记录为 0。完整书库实算三条独立模式及融合均获得 20 本正分候选，矩阵有 200 个读者，选择 15 位相似读者，Top-N 实际处理 689 个未读候选。该数字记录当前演示规模，不是推荐准确率评估。
