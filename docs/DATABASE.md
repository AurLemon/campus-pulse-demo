# 数据库、身份与事务

## 存储与初始化

产品通过 `packages/domain/prisma.ts` 使用 Prisma 7、better-sqlite3 适配器和 SQLite。默认数据库 `.data/pulse.db`，旧 `.data/campus.db` 为保留的旧状态，不被当前默认配置读写。Prisma schema 位于 `prisma/schema.prisma`，生成 Client 位于 `generated/prisma`。

```sh
pnpm db:generate
pnpm db:push
```

当前开发采用 schema push，可直接重建开发数据库，不要求维护旧迁移链。重建前保存可恢复快照，对已有真实账户/内容不得随意强制覆盖。

应用可用 `CAMPUS_DATA_DIR` 配置数据目录，`DATABASE_URL` 优先级更高。CLI 和应用均建议使用同一绝对 `file:` URL，所有命令从仓库根运行。SQLite 与媒体是两个需要一起备份的持久单元。

## 实体

| 实体                   | 职责                                               |
| ---------------------- | -------------------------------------------------- |
| User                   | 公开昵称、兴趣、角色，账户与密码材料仅服务端使用   |
| AuthSession            | 持久会话，保存随机 token 的 SHA-256 摘要及过期时间 |
| Activity               | 组织者、标签、时间地点、容量、状态和封面关联       |
| Post                   | 作者、正文、表现类型、内容用途、媒体、可选活动关联 |
| Comment                | 具体帖子的一级评论与一层回复                       |
| Friendship / Follow    | 需接受的双向好友语义与单向关注                     |
| State                  | 当前有效点赞、收藏、报名，撤销改变当前状态         |
| Behavior / ViewSession | 历史逻辑行为和阅读会话，不把心跳数当阅读次数       |
| MediaAsset             | 媒体路径、宽高、替代文字、归属及来源记录           |
| ContentImportReceipt   | 导入批次、摘要、数量与幂等回执                     |

保留的 DemoMeta 不决定产品时钟，产品读取当前业务时间。完整 Snapshot 仅作为服务端算法输入与工具交换结构，不能将密码或完整行为库作为 bootstrap 返回值。

## 身份与权限

用户注册获得 STUDENT。组织者与管理员通过本地受控命令设置，客户端不能声明自己的角色。密码由独立随机盐和 scrypt 派生值保存。会话 token 随机生成，Cookie 为 HttpOnly、SameSite=Lax，HTTPS 请求下设置 Secure，30 天过期。退出删除当前会话。

公开查询允许游客。写操作要求有效会话，活动写入和管理需校验角色与对象归属。写请求校验来源，登录/注册有进程内限流。账户恢复、邮件验证和多实例限流仍需后续能力。

## 查询与分页

bootstrap 只返回当前公开用户、主题和校区。资源详情与侧栏使用独立 DTO 查询。推荐输入仍在服务端读取完整关系与行为快照，当前不是按数据库索引完成的大规模召回系统。

推荐内容流首次计算一个稳定排序会话，最多保留 200 个进程内会话，30 分钟过期。游标绑定身份、筛选与会话，分页跳过已删除项，并根据实际剩余项给出 hasMore。进程重启或会话失效返回 FEED_EXPIRED，多实例需要共享会话状态。

## 写入与导入边界

报名、撤销及行为写入由对应领域操作控制事务，报名数量以有效 State 计算。关联帖不保存另一套名额。好友与关注语义独立，未接受请求不参与好友证据。

工具调用 `importContentBatch` 提交内容和媒体元数据。导入校验引用、角色、标签、时序、媒体存在性与内容约束，批次内容摘要用于幂等与冲突判断。事务成功后才触发可选 `onPublished`。hook 失败记录返回错误，内容已经提交，不能当作导入回滚重试。

旧快照导入函数保留在工具边界，恢复会拒绝包含真实内容的数据。产品没有 HTTP 重置、模拟身份或任意文件导入接口。

## 媒体

上传要求登录，multipart 单文件，文件正文最多 8 MiB，请求总量最多 9 MiB。sharp 校验实际 JPEG/PNG/WebP，输入像素上限 4000 万，按方向旋转、限制输出尺寸并转 WebP。数据库写入失败时清理新文件。

随仓库提供的素材通过 `tools/content/assets.tar.gz` 维护，导入前自动恢复到 `.data/assets-cache` 再复制到媒体目录，不包含用户上传。文件保存在 `CAMPUS_MEDIA_DIR` 或默认 `.data/media`，响应 URL 为受限制的 `/media/:file`，不得接受任意路径。产品发布只能引用自己拥有的已上传资源。素材出处和使用条件另由工具记录保留。

## 验证边界

静态检查、接口行为、事务竞争和浏览器交互分别验证。当前结构适用于单机项目，不能从 SQLite 本地成功推断反向代理、容器卷、Windows/Linux 原生依赖或多实例已验收。

## Studio 只读连接与并发

主站写连接启用 WAL，Studio 使用独立 readonly/fileMustExist 连接，通过短事务读取与主站一致的算法输入，随后关闭连接。Studio 不导入主站写客户端，不创建文件或执行迁移。数据路径沿用主站默认值，可显式设置 NUXT_STUDIO_DATABASE_URL，错误时不读取替代库。读取事务不跨计算或界面交互持有，SQL 写入由驱动拒绝。
