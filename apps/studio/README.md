# 在场 Studio

Studio 是主站数据的只读观察界面，使用独立的 SQLite 只读连接读取主站数据库，在内存中调用相同的推荐包。连接启用 readonly 与 fileMustExist，不创建数据库，不写业务表，不读取离线 seed 或旧快照作为回退。用户、帖子、活动、状态和有效浏览记录均来自主站当前数据库，密码、登录账户字段和认证会话不返回 Studio。

从仓库根目录分别运行：

```sh
pnpm dev
pnpm dev:studio
```

主站为 127.0.0.1:3000，Studio 为 127.0.0.1:3001，默认共享根目录的 `.data/pulse.db`。两边沿用相同 DATABASE_URL / CAMPUS_DATA_DIR 规则，可通过 NUXT_STUDIO_DATABASE_URL 显式指定 Studio 的只读来源。文件不存在、数据库读取失败或没有业务数据时直接显示错误，不能自动创建库或降级到离线内容。生产观察工具也只绑定本机回环地址，不作为公共入口部署。

主站写连接使用 WAL 与有限 busy timeout，Studio 使用短只读事务读取一致快照，读取完成关闭连接，不持有长事务。恢复实验数据入口已禁用，显式主站账户登录入口保留，观察与计算不提供主站业务写入路径，主站的正常登录、点赞、收藏和报名仍由主站完成。

默认使用实时计算时间，页面每 3 秒轻量检查数据库/WAL 变化，窗口获得焦点时立即检查，有更新才重新读取并计算。可以关闭实时同步并编辑固定基准时间，此时只按该时刻的证据计算，后续新行为可能不计入。刷新失败直接显示错误，不将旧结果当作实时数据继续展示。

阶段、观察用户、活动/帖子、K、时间模式与四项权重写入路由，刷新与浏览历史恢复设置。换一批/重新计算使用新探索种子，普通调参和数据更新保留本轮种子，便于比较。评分页展示四项匹配贡献与探索的真实混合公式，Top-K 图形、记录与最终结果来自同一次计算。

追踪最多记录 10000 个正常步骤及一个截断标记，达到上限会明确提示，最终推荐仍完整计算。`/feed` 同样读取主站数据，只用于内容预览，不发送阅读或互动请求。减少动态偏好下关闭自动播放。

开发环境保留“切换主站账户”，这是用户显式触发的主站认证操作，由受限 HTTP 通道让主站建立登录会话，不经过 Studio 的只读数据库连接，不修改密码、角色或业务内容，生产构建仍禁用该认证桥接。
